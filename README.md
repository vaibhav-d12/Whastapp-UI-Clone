# 💬 WhatsApp UI Clone (HTML & CSS)

This project is a **WhatsApp Web UI Clone** built using **HTML5 and CSS3**.
The goal of this project is to practice **frontend development skills** by recreating a real-world application interface.

🚧 **Note:** This project is currently under development and being uploaded in parts (incremental updates).

---

## 🚀 Features

* 📱 WhatsApp Web-like layout
* 💬 Chat interface design
* 🧑‍🤝‍🧑 Sidebar with contacts list
* 🔍 Search bar UI
* 🟢 Status indicators
* 🎨 Clean and responsive design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* (Planned) Responsive Design Techniques
